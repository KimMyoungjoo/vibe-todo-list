# vibe-todo-list

## 1. 프로젝트 개요
- 주제: 바이브코딩을 이용한 To-Do 웹 앱 개발
- 개발 환경: HTML, CSS, JavaScript
- 사용 AI: Gemini

## 2. 요구사항

### 2-1. 기능적 요구사항
- 할 일 추가: 사용자는 새로운 할 일을 생성하고, 텍스트를 입력 할 수 있음
- 목록 조회: 저장된 할 일 목록을 화면에 표시함
- 삭제 기능: 불필요한 항목을 삭제

### 2-2. 비기능적 요구사항
- 사용성: 별도의 설명서 없이도 직관적으로 사용할 수 있는 인터페이스
- 반응성: 할 일 추가 및 삭제 시 즉각적으로 화면에 반영
