# vibe-todo-list

## 1. 프로젝트 개요
- 주제: 바이브코딩을 이용한 To-Do 웹 앱 개발
- 개발 환경: HTML, CSS, JavaScript
- 사용 AI: Gemini

## 2. 요구사항

### 2-1. 기능적 요구사항
- 할 일 추가: 사용자는 새로운 할 일을 생성하고, 텍스트를 입력 할 수 있음
- 목록 조회: 저장된 할 일 목록을 화면에 표시함
- 삭제 기능: 불필요한 항목을 삭제

### 2-2. 비기능적 요구사항
- 사용성: 별도의 설명서 없이도 직관적으로 사용할 수 있는 인터페이스
- 반응성: 할 일 추가 및 삭제 시 즉각적으로 화면에 반영

## 3. 시스템 설계

### 3-1. 아키텍처 스타일
- 클라이언트 사이드에서 모든 로직을 처리
- 사용자 입력(UI) -> 자바스크립트 처리 로직 -> 로컬 스토리지에 저장

### 3-2. 데이터 저장 방식
- 브라우저의 LocalStorage 사용
- 이유: 별도의 DB 서버 구축 없이 구현 가능하고, 사용자 기기 내에서 독립적으로 동작하므로 응답 속도가 빠름

### 3-3. 데이터 구조
각 할 일 항목을 JSON 형식으로 관리한다.
```json
{
  "id": "고유 ID",
  "text": "할 일 내용 (String)",
  "completed": "완료 여부 (Boolean)",
  "createdAt": "생성 시점의 timestamp",
  "deletedAt": "삭제 시점의 timestamp. soft delete 구현",
}
```

### 3-4. 기술 스택
- Frontend: HTML, CSS, JavaScript
- Storage: 브라우저 로컬 스토리지(LocalStorage)
- AI(바이브코딩): Gemini 3

### 3-5. UI/UX
- Top: 앱 타이틀 및 검색, 할 일 추가 버튼
- Main: 할 일 리스트 표시. 각 할 일 항목은 체크박스, 내용, 수정 버튼으로 구성
- 할 일 작성 및 수정 창: 내용 입력, 저장 버튼, (할 일 수정의 경우) 삭제 버튼
